# 演示数据来源与使用边界

## 数据构成

`tests/corpus` 中的“星云科技”及全部制度均为本项目生成的合成演示材料，不对应任何真实公司、员工、客户或业务数据。制度中的内部审批额度、时限和福利均为测试设定。

语料覆盖：

- 员工手册与申诉
- 考勤、年休假和公司福利假
- 差旅申请、住宿标准和报销
- 数据分级与安全事件报告
- 远程办公
- 绩效反馈和改进计划
- 入职、转正、离职和权限回收
- 员工福利与学习预算

## 公开法规参考

为避免演示材料在基础休假规则上出现明显错误，年休假和法定节假日部分参考了以下政府公开页面：

- 司法部国家行政法规库：《职工带薪年休假条例》
  https://xzfg.moj.gov.cn/front/law/detail?LawID=208
- 中国政府网：《全国年节及纪念日放假办法》（2024年修订，自2025年1月1日起施行）
  https://app.www.gov.cn/govdata/gov/202411/12/521605/article.html

项目没有复制真实企业员工手册，也没有把政府网页全文放入知识库。法规链接只用于说明设计参考，不代表项目提供法律意见。

## 使用建议

演示时应明确说明“星云科技”为虚构公司。若改为真实企业部署，应由企业 HR、法务、信息安全和财务负责人提供并审核正式制度；不得直接把本合成语料作为企业制度使用。
